Night Owl

One open-source tool that scans your code, dependencies, secrets, infrastructure files and containers, then keeps itself up to date. It is built as an open alternative to Black Duck, Coverity, SonarQube and Fortify.

What it does, in plain words

Security scanning usually means running five different tools, reading five different reports, and keeping all five up to date. Night Owl does that for you:

  1. It runs proven open-source scanners (called engines) in containers, at exact, signed versions.
  2. It converts everything they report into one common format, and removes duplicates when two engines report the same problem.
  3. It gives you one report, one pass/fail quality gate, and one dashboard.
  4. It updates its own engines safely, and checks that an update still works before keeping it.

Night Owl does not invent new scanners. Its value is in the glue: consistent results, stable IDs, a sane gate, and updates you can trust.

What it checks

Vulnerable dependencies

Known CVEs in the libraries you use, plus licenses and a full SBOM.

Your own code (SAST)

SQL injection, command injection, XSS, unsafe deserialization and more, including data-flow (taint) tracking.

Secrets

Keys and tokens in current files and in git history. The secret value is never saved.

C and C++ defects

Out-of-bounds access, use-after-free, double free, leaks.

Infrastructure as code

Terraform, Kubernetes, Dockerfiles, Helm, CloudFormation and more.

Container base images

Known vulnerabilities in the images your Dockerfiles build on.

Code quality

Complexity, duplication and test coverage, each with an optional gate.

Running apps (DAST)

Optional, authorized active testing of a staging site, planned by an AI model.

Try it in three steps

  1. Install it. You need Docker running. 
    curl -fsSL https://raw.githubusercontent.com/finepointcgi/Night-Owl/main/scripts/install.sh | sh
  2. Scan a project. 
    nightowl scan path/to/project
  3. Read the result. You get a table of findings and a pass or fail. Exit code 0 means it passed.

New here? Getting started walks through every step and shows what the output means.

Honest limits

Night Owl orchestrates open-source engines. It will not match Coverity's deep whole-program C/C++ analysis, or Black Duck's binary and snippet matching. Expect it to find the common, serious problems, in one place, with fewer false alarms than running the raw tools. See known limits for the full list.
